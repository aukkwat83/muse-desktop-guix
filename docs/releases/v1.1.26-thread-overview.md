# v1.1.26 — ChatGPT Desktop parity: turn headers, chips, thread overview, goal strip

Parity pass that makes turn / subagent / goal / task display match
`ilysenko/codex-desktop-linux` (ChatGPT Desktop) as far as the Muse CLI
feed allows.

## What changed

- **Live + settled turn headers** — every turn shows a header row:
  live turns read `กำลังทำ Xs · n เครื่องมือ · m เอเจนต์`, settled turns
  read `ทำไป Xs` (Thai labels; English fallback when `LANG=C`).
  Header ticks every 500 ms while a turn runs.
- **Turn duration persisted** — server records `durationMs` in per-turn
  transcript meta, so history keeps real durations across reloads.
  Old transcripts without the field fall back to message counts.
- **Chips** — thread chips (`Tmp files`, `Host date`, …) render above
  the input like the reference; agent rows render as `✳` chips.
- **Thread overview (`▦`)** — new header button opens an
  Outputs / Subagents / Tasks / Goal popup mirroring the reference
  overview (counts + done states).
- **Composer goal strip** — active goal shows above the composer with
  pause/resume, fed by the existing SSE `goal` block.
