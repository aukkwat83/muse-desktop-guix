## On the reference (read first)

`ilysenko/codex-desktop-linux` is a **repackager** of OpenAI's signed,
closed-source ChatGPT desktop app — it contains no ChatGPT UI source to
copy (the Electron `app.asar` is reused byte-for-byte; the repo only owns
verification, packaging, and small patch descriptors). What follows is
therefore an **approximation** of the observable ChatGPT-desktop patterns,
not a copy:

- Authored messages stay visible in order; tool activity stays collapsible
  (already this app's shape: answer bottommost, progress groups collapsed).
- A spawned child reads as a **nested activity block**: status + step rows
  under the parent turn, expandable inline — this release.

## What changed

- **Server** (`sessions.js`): every tool row resolves `agentLink` — the
  registry key (`native:<subagent_id>`) when the row names a durable
  child, else absent. Rides `tool_call`/`tool_call_update` SSE and
  persists in `msg.meta.toolCalls`, so history rows link too. Pure
  `agentRowLink()` + wire test in `unit-test-subagents.mjs`.
- **Renderer** (new `child-activity.js` + `app.js` wiring + 6 CSS rules):
  linked agent rows grow a `.child-activity` block above the console —
  status headline + step rows from the drill endpoint, a live tail while
  running, graceful fallback when the child record is gone. Loads on
  first expand only; repaints never wipe a loaded block; status
  transitions refetch, deltas patch the tail. One level deep — the
  "แผงขวา ›" button opens the full rail drill.
- **Suite**: `test:child-activity` (summary + headline), registered in
  `npm test` (now 39 suites).

## Honest bounds (what the wire cannot show)

- Model-side `Agent` rows carry a type but **no durable child id** — they
  stay unlinked (console-only), same as before.
- Plan todos carry `{text, status, activeForm}` with **no link to tool
  activity** — per-task activity expansion has no data and was not built.
- Goal block already matches the pattern (objective + bar + pause/resume).
