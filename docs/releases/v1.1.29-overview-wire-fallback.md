# v1.1.29 — Overview Subagents fall back to wire children

Bug: with subagents running, the agents chip counted them but the `▦`
thread overview claimed `ยังไม่มี subagent ในเทรดนี้`. The chip falls
back to the server's wire registry when the live turn has no agent
tool rows (`updateAgentsChip`); the overview never did — it only read
the live turn view.

## What changed

- `src/renderer/rightbar.js` — new pure view-model
  `overviewSubagentRows(agentTools, wireRecs)` (+ `OVERVIEW_WIRE_CAP =
  6`): live-turn rows win; else wire records newest-first, real
  children first capped at 6 with a hidden count, reminders folded to
  a count + running count. Module token `1.1.3` → `1.1.4` in all
  three importers (`app.js`, `child.js`, `child-activity.js`).
- `src/renderer/app.js` — overview Subagents section paints the
  descriptors: turn rows as before; wire rows reuse the rail's
  `subagentTitle` / `subagentStatusWord` / `subagentSub`, an
  `อีก n subagents` row past the cap, and one `⏳ reminders · n`
  row with a `กำลังรัน r` trailing. All rows drill to the agents
  rail.
- `scripts/unit-test-subagents.mjs` — two tests for the seam
  (turn-wins / wire-fallback / empty; newest-first + cap + reminder
  fold).
