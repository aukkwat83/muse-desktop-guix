## Summary

The mac v1.0.0 host was already 90% of the way to Linux: the rasterizer,
`revealFile`, `/api/auth/login` and `/api/pick-files` all had platform branches,
and the shell contract (`/api/state`, `/api/version`, `/api/memory`,
`POST /api/host/shutdown`) matches grok's exactly — so the GTK shell is a
faithful port, not a redesign.

### What the shell carries

- **Reload (R39).** 🔄 and **Ctrl+R / Ctrl+Shift+R / F5** purge the HTTP cache
  (disk+memory) then `webkit_web_view_reload_bypass_cache()`. Cookies and
  localStorage (the theme choice) survive. **Renderer only.**
- **Restart host (R58-guix).** Second header-bar button, mirroring mac's
  `HostSupervisor.restart()` (the "รีสตาร์ท host" menu action): graceful
  `POST /api/host/shutdown {killAgents:false}` (warm agents survive) →
  `/proc`-verified SIGTERM only if HTTP never lands → wait for the port →
  start → wait healthy → cache-ignoring reload. Timeout-driven (500 ms ticks),
  so the window never freezes. Exposed as the `app.restart-host` GAction.
- **Web Inspector (R58-guix).** `developerExtrasEnabled` parity with
  `ContentView.swift` — right-click → *Inspect Element*. Console→stderr stays
  opt-in via `MUSE_DESKTOP_DEVTOOLS=1`.
- **cardDrag bridge (R50), dormant.** Registered (`window.webkit.messageHandlers.cardDrag`
  will exist), but neither shell nor renderer implements the sender yet —
  diagrams use the in-page ↓ SVG / ↓ PNG buttons. A future renderer sender gets
  file drops with no shell change.
- **Memory meter** reading the muse `/api/memory` shape
  (`Hot h/max · Running r · Free x`).

### What the host gained

- **Attach picker on Linux.** `/api/pick-files` drives zenity/qarma/yad/kdialog
  via `src/server/file-picker.js` (per-request resolution, real-newline
  separators, cancel-vs-error distinction). The old hard
  "macOS only" dead-end is gone.
- **Darwin-only PAC fallback.** `defaultPacProxy()` keeps the mac default
  (`SCB_PAC_PROXY` → `127.0.0.1:39080`) and returns `''` on Linux, where that
  bridge does not exist and would break agent TLS. Explicit env wins everywhere.
  `deploy.sh` applies the same rule, and knows how to build/stop/open per
  platform.
- **Ctrl+N** for new session alongside Cmd+N (find-in-chat already accepted both).

## New guards

- `npm run test:guix-shell` (**16/16**) — the C contracts (R50/R39/R58 +
  Inspector), the stale-binary guard, the prebuilt fast path, and the
  symlink-safe ROOT rule (HAZ-10). The grok-only `grok-config` dir-watch test
  was replaced with the HAZ-10 test.
- `npm run test:guix` (**18/18**) — manifest closure, desktop entry, systemd
  service, picker pure rules, PAC fallback per platform, route wiring,
  launcher +x bits, package scripts.
- Both suites are registered in `unit-test-all.mjs`, so `npm test` covers them
  on mac too (the binary checks skip when never built).

## Verification
