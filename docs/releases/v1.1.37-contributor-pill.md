# v1.1.37 — Contributor switch moves beside the effort pill

Previous: v1.1.36

v1.1.36 put the contributor on/off switch at the bottom of the cost rail,
where users could not find it — and worse, the switch shipped invisible:
each renderer module carries its own `?v=` import token
(`rightbar.js?v=…` inside app.js), which the release had not bumped, so
browsers kept serving the stale module while every version check stayed
green. This release moves the switch and closes that cache hole.

## What changed

- `src/renderer/app.js` + `index.html` — new `contrib-chip` pill right
  after the effort pill (`contributor`/`standard`, existing `pill mode`
  style, no new colors): always visible once the mode is known, optimistic
  flip with rollback on error, disclosure notice in the title so the click
  is the informed consent.
- `src/renderer/rightbar.js` — rail switch removed (the rail keeps its
  read-only mode row); new `refreshPricing()` entry so the pill repaint
  also refreshes the priced rows. `rightbar.js?v=1.2.1`.
- `scripts/unit-test-css-guards.mjs` — new pin: every relative renderer
  import must carry a non-empty `?v=` token, so a stale-module release
  fails the gate instead of shipping invisible.
- Shared `?v=` + package version → 1.1.37 together (BUG-078).
